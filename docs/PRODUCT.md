# 产品范围

## 产品目标

将高频截图流程压缩为：

> 快捷键 → 冻结屏幕 → 自动识别窗口或手选区域 → 直接标注 → 输出 PNG

截图完成后可以复制到剪贴板、保存本地、进入历史记录，并在后续版本中发送到用户选择的 AI 目标。

## 第一阶段范围

- Windows 全局快捷键；
- 多显示器静态截图；
- 窗口、控件与矩形区域候选；
- 冻结画面上的箭头、矩形、文字、马赛克、序号和画笔；
- 撤销、重做、复制、保存和取消；
- SQLite 截图索引与本地 PNG 文件；
- 历史记录浏览、复制、另存为和删除；
- 设置页：快捷键、默认输出、命名规则和保存路径。

## 暂不包含

- 视频与 GIF 录制；
- 上传图床；
- OCR 和长截图；
- 云同步；
- 自动调用付费 AI API；
- macOS/Linux 发布。

以上能力必须在核心截图链路稳定后，通过独立里程碑评估。

## 非功能要求

- 快捷键触发到冻结画面目标小于 150 ms，最终以基准测试为准；
- 取消截图不得写入历史或产生临时 PNG；
- 多屏不同 DPI 下，选区逻辑坐标和像素坐标必须可验证；
- 用户图片默认只保存在本机，不执行隐式上传；
- 崩溃后不破坏已有历史数据库。

## 验收主路径

1. 用户按下快捷键；
2. 桌面冻结，鼠标移动时高亮候选窗口；
3. 用户拖动调整选区并添加标注；
4. 用户按 Enter，得到 PNG 并复制到剪贴板；
5. 历史页出现一条可再次复制和打开的记录。
